## 核心规则速记
- 优先级：🔴 P0 阻塞（必须清零）/ 🟠 P1 重要 / 🟡 P2 建议 / 🔵 P3 优化
- 合并门槛：CI 全绿 + ≥1 批准（核心/安全 ≥2）+ 所有 P0 清零
- 注释格式：`优先级 + 分类 + 文件:行 + 为什么 + 建议`
- 当前基线以 `docs/project-review-2026-11-03.md` 第十节为准；历史债务清单已清理，新 PR 不得新增同类问题
